## 项目内容

本项目以 AI 产品为灵感，创作非官方的拟人角色、人物关系与漫画创作设定。人物背景、关系、台词和情节均为虚构，不代表相关模型、公司或产品的真实性格、内部信息或官方立场。

本仓库仅包含：

- 角色卡/AI角色：八张 ZipZipPipe 系列参考角色卡、DSH 衍生卡及 GPT-6 ASTRA 特殊形态图。
- 角色卡/主人形象：AI 生成的虚构男性上班族「主人形象」参考卡。
- 角色设定与创作手册.md：完整人物设定、创作原则和参考来源。

漫画成品、分镜、提示词、历史资产、辅助图和其他项目资料均不在本包内。

## 角色卡素材说明

本包不收录网上找到的原始参考图片。角色卡成品由作者委托 AI 生成／修订，卡片版式与成图由本项目重新制作，并非直接转载上游原图。DeepSeek、GPT、Claude、Gemini、Grok、GLM、Kimi、Qwen 八张基础卡的角色形象参考 ZipZipPipe 发布的对应 AI 娘角色；“卡片成品重新制作”与“角色形象参考来源”是两件事。角色对应的公开来源线索和 Pixiv 使用条件的两份核验记录见 SOURCES_AND_RIGHTS.md。上游角色不归本项目所有；按记录的条件署名、非商业使用。
